Finance-RL Trading Agent

Offline RAG Code Tutor

Fully offline RAG system indexing 8,528 RAPIDS cuDF files into ChromaDB, powered by Qwen2.5-Coder-14B via LM Studio. Three modes: Code Gen, Bug Hints, and GPU Optimisation — zero cloud dependency.

Tesla Speed Optimizer

End-to-end PySpark ETL pipeline analyzing 441K rows of Tesla Model 3 CAN-bus telemetry to identify the optimal driving speed (70 km/h) that maximizes energy efficiency while minimizing trip duration.
